# AI Working Contract — AMRHZ Ecosystem

Before updating the ecosystem registry, read [the standards registry](docs/STANDARDS-REGISTRY.md).

- Treat this repository as an index of projects and standard adoption, not a second source of canonical policy text.
- The canonical governance standards live in [amrhz-architecture-core](https://github.com/amirulhafiz1132002-code/amrhz-architecture-core/tree/main/docs/standards).
- Record each project's adoption status only from inspectable repository evidence or a linked pull request.
- Distinguish PROPOSED, ADOPTED, VERIFIED, ENFORCED, BLOCKED, and UNKNOWN. A link or copied document alone does not prove enforcement.
- Do not mark a standard as approved or enforced while its canonical PR remains unmerged or the relevant checks remain unverified.
- Do not edit application repositories or change their UI from this registry task.
- Keep this registry concise; link to the source of truth instead of duplicating policy text.
